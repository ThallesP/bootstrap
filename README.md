# Bootstrap

Bootstrap is a small English program for LLMs. It gives an agent a sequential flow for bootstrapping a modern TypeScript app: ask for the right context, pick tools by category, get approval, then scaffold with official CLIs.

[![Ben Davis on English-as-code for agents](https://img.youtube.com/vi/n6nF6jhsal4/hqdefault.jpg)](https://www.youtube.com/watch?v=n6nF6jhsal4)

Install with [skills.sh](https://skills.sh):

```sh
npx skills add ThallesP/bootstrap
```

Or install from a checkout:

```sh
./setup
```
