# API Keys

| Tool | Choose When | Avoid When | Official CLI / Init |
| --- | --- | --- | --- |
| Unkey | API key management, rate limits, usage controls, developer platform access keys | The product has no external API, SDK, or machine-to-machine access | Unkey SDK or dashboard setup |
| Clerk API keys | The app already uses Clerk and only needs simple API keys tied to its auth model | API keys are a core product surface, need dedicated rate limits, usage controls, or provider-neutral key management | Clerk docs and SDK setup |
